# Hermes Web 5.0.0

信使 Hermes 的网页客户端，对齐 iOS 5.0 中所有与 Hermes 服务器相关的功能。界面中的版本号来自 `core.js` 的 `VERSION`。

## 包含

- **工作台「待处理」**：待审批、运行中和需关注的定时任务、本标签页观察到的运行结果。待审批数量显示在工作台入口和页面标题上；卡片可打开对应会话或任务，完整列表在「收件箱」。
- **对话**：服务端会话每次加载 50 段，可继续加载更早的会话；搜索已加载的会话，置顶优先，标出来源、消息数和运行状态（运行中、待审批）。可新建、置顶、重命名、删除，复制或下载已加载的记录。
- **会话内容**：与 iOS 相同的消息样式。Hermes 回复按 Markdown 显示，工具输出和系统消息为紧凑卡片，未执行的轮次带「本轮未执行」标记；审批卡、运行状态条、停止和「改口」都在会话内。可加载更早的消息、查找已加载消息、发送文字和单张图片。
- **不自动重发**：连接中断或回复失败后，先刷新服务端记录，再把服务端没有保存的文字或图片放回输入区，由你决定是否再发送。
- **定时任务**：概览、状态筛选、搜索、前台定时刷新（失败后放慢）、详情、新建、编辑（只提交改动的字段）、复制为新任务、暂停与恢复、立即运行、删除。只调用 iOS 使用的接口。
- **连接**：默认连接（工作台 Tailscale）保持原有行为；一个自定义连接可手动填写。配对码与 iOS 相同：在支持 `BarcodeDetector` 的浏览器中用相机或图片扫码，所有浏览器都可以粘贴配对码文字或带 `pair` 参数的链接；也可以显示当前自定义连接的配对码，让 iPhone 扫码添加。
- **外观**：跟随系统、浅色或深色。

## 不包含

iOS 保存在设备上的内容不在网页中：本机对话、项目、知识资料、消息库与收藏、本机草稿和 JSON 备份。网页不在浏览器中保存会话内容；输入区的文字只在当前页面打开期间保留。

## 连接与密钥

- **默认连接**：工作台在页面中注入 `hermes-workbench-url`。请求直接发往该地址并带 `X-Hermes-Workbench: 1`，API 密钥由中继保管，浏览器中没有密钥，因此默认连接不能显示配对码。
- **自定义连接**：与以前的版本相同，服务地址和 API 密钥保存在这个浏览器的 `localStorage`（`hermes.serverURL`、`hermes.apiKey`）。`localStorage` 按来源共享，同一工作台来源下的其他应用也能读取，所以网页只保存一个自定义连接；扫码或粘贴配对码会替换它，不会存入第二把密钥。
- **其他存储**：`localStorage` 另外只保存非密钥的偏好（连接名称、外观、任务刷新间隔、中继路由是否已放行）。本标签页观察到的运行结果放在 `sessionStorage`，关闭标签页后清除。
- **地址规则**与 iOS 相同：远程服务要求 HTTPS；HTTP 只接受 `localhost`、`.local` 主机名和私有 IPv4。HTTPS 页面会被浏览器禁止访问局域网 HTTP，请在本机运行 `serve.py`。从工作台直接连接自定义服务时，服务需允许工作台来源（CORS）。
- 配对码包含 API 密钥，只向自己的设备出示。回环地址（`localhost`、`127.*`）不出码。

## 默认连接的中继路由

工作台中继（`project-private-web/scripts/hermes-relay.mjs`）目前只转发模型、会话列表与新建、删除会话、消息、续聊、审批和停止。定时任务、置顶和重命名还需要放行：

```js
[/^\/api\/sessions\/[\w-]+$/, ['GET', 'PATCH', 'DELETE']],
[/^\/api\/jobs$/, ['GET', 'POST']],
[/^\/api\/jobs\/[\w-]+$/, ['GET', 'PATCH', 'DELETE']],
[/^\/api\/jobs\/[\w-]+\/(pause|resume|run)$/, ['POST']],
```

放行前，网页显示「默认连接暂不支持」，并且不发送这些请求（被拒的跨域预检会在浏览器控制台报错）。更新中继后，点一次「中继已更新？仍然尝试」，这个浏览器会记住。

## 运行包文件

`index.html`、`styles.css`、`core.js`、`app.js`。`core.js` 是 5.0.0 新增的文件，发布时需与 `app.js` 一起放到 `workbench-runtime` 分支根目录。从私有工作台打开时，服务必须是 HTTPS，并允许对应工作台来源（CORS）；局域网 HTTP 仍用本机代理。

## 本机运行

```sh
python3 web/serve.py
```

浏览器打开 http://127.0.0.1:8787/ ，填写 Hermes API 地址和密钥，或粘贴配对码。本机代理逐段转发流式回复。

## 检查

```sh
python3 web/protocol_test.py
```

检查地址规则、本机代理（方法、查询参数、请求体、密钥、流式回复逐段到达）；有 Node 时运行 `protocol_test.js`，用 iOS 测试中的数据检查 `core.js`，再经代理对模拟 Hermes 服务调用全部接口，并核对实际发出的请求。

界面检查可启动带演示数据的模拟服务（密钥 `mock-key`）：

```sh
python3 web/protocol_test.py --mock 18299
python3 web/serve.py 18200
```

在 http://127.0.0.1:18200/ 填写 `http://127.0.0.1:18299` 和 `mock-key`。消息包含「审批」「慢」「失败」「断开」「未保存」时，模拟服务分别演示审批、可停止的长回复、运行失败和连接中断。加 `--relay-origin <页面来源>` 时，模拟服务同时按当前中继路由充当默认连接。
