# 信使 Hermes · 产品与商业化分析（摘要）

> 编写日期：2026-11-28。外部数据的访问日期均为 2026-11-28，另有标注的除外。「估算」表示推算，「待核实」表示只找到二手来源。
> 详细内容：[产品分析](product-analysis.md) · [商业化分析](commercialization.md)

## 一句话定位

给自建 Hermes Agent 用户的原生 iPhone / iPad 工作区：在手机上续聊、审批、管理定时任务，并把项目资料、消息库和草稿留在本机。

## 目标用户

- **主要用户**：已经在 Mac、家用服务器或 VPS 上运行 Hermes Agent 的个人开发者和技术型产品人，需要离开电脑时继续推进任务。
- **次要用户**：把 Hermes 当作长期研究或写作助手的知识工作者，需要按项目整理资料，并明确控制每次发送的上下文。
- **内部用户**：Allen 本人。网页版通过私有工作台 hub.openmakers.cn 的「信使」卡片使用。

## 关键结论

1. **「官方没做、第三方来补」的窗口正在关闭。** Nous 已开放官方 Hermes Mobile Beta 候补名单。二手报道称，iOS 版于 2026-10-31 前后通过 TestFlight 发放（待核实）。Nous 的付费套餐还附带 Hermes Cloud，可以直接在手机浏览器使用。这推翻了 [2026-11-13 调研](../research/third-party-agent-clients/README.md)中「Nous 没有官方 App」的前提。
2. **商店里同类客户端全部免费。** Hermex（232 个评分）免费，也没有内购。同类中真正收费的只有 Moshi，它卖的是多 Agent 的 SSH / Mosh 终端（Pro 每月 US$9.99），不是 Hermes 专属客户端。
3. **真正的差异是本机知识工作区。** 项目资料、引用、消息库、统一检索和草稿保护，Hermex 和官方 App 的公开文案里都没有。服务端能力（diff、推送、看板）则是 Hermex 领先。
4. **规模信号偏小。** Hermes Agent 有 26.7 万 star，但 Hermes 客户端在美国 App Store 的评分最多两百多个。评分数不等于下载量，用户量待核实。
5. **上架有实际门槛。** 需要应对 App 审核 5.1.2(i) 对第三方 AI 数据共享的披露和同意要求，为审核提供可用的演示服务，并避开「Hermes」商标。

## 推荐模式

**近期（0–6 个月）把它当作自用工具和开源作品，不急于收费。** 先用低成本实验验证「本机项目工作区」是否有人愿意付费。验证通过后，采用免费下载加一次性买断 Pro 的方式：建议 US$9.99 / ¥68 起，只锁定工作区高级功能，续聊和审批保持免费。不做订阅，因为它不承担任何模型或服务器成本。定价依据见[商业化分析](commercialization.md#3-商业模式与定价)。

## 接下来三件事

1. **对标官方 Beta 和 Hermex（1 周）。** 申请官方 Hermes Mobile Beta，安装 Hermex，按同一组 5 个任务记录差距，决定停止哪些通用聊天功能、加强哪些工作区功能。
2. **补齐 v5 真实环境验收（1 周）。** 在真机上连接真实 Hermes 网关，跑通续聊、审批和定时任务。同时决定许可证：开源用 MIT，或明确闭源。
3. **小范围外部 Beta（4 周）。** 准备 TestFlight 外部测试（需要 Apple Developer Program，每年 US$99），在 Hermes 社区招募 30 名用户，按[验证实验](commercialization.md#7-低成本验证实验)的指标决定是否上架。
